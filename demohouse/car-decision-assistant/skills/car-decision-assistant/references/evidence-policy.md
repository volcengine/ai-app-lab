# 证据政策

1. Agent Plan 只结构化用户需求，不生成车型事实。
2. 专业数据集结果必须绑定本次用户选择的精确车型标识。
3. 车系级、年款级或其他配置数据不能写入精确配置事实。
4. 城市车系数据必须校验城市、车系、月份和统计口径。
5. 不同销量口径只分别展示趋势，不横向比较绝对值。
6. 指导价不能替代落地价；落地价由用户录入完整报价。
7. 主观体验、口碑、保值率、保险和补能便利保持本人确认或能力不支持。
8. 上游无原生 code 时可冻结精确名称标识，但不得伪造 code。
9. 每项专业证据保留来源、时间、状态和可用 trace/request ID。
10. 数据缺失、超时或结构异常应显示原因，不使用模型记忆补齐。
