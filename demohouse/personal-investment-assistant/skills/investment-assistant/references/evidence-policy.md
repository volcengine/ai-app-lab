# 证据与生成协议

## 来源职责

- DataPro：行情、财务指标及其他专业结构化数据，不标注为新闻来源。
- 豆包搜索：公告、新闻、政策和公开网页。生成与审校阶段临时使用接口返回内容；历史记录保留标题、URL、发布方、日期，以及由已审校正文派生的来源摘要，不持久化接口原始摘要或完整响应。正文头部存在明确“来源：”署名时，以原始发布方作为 publisher，并另存转载托管站点。
- Agent Plan 模型：整理与分析已检索证据，不提供独立事实来源。
- 系统检查记录：只用于内部审计检查区间、时区和监控内容，不作为公司事实来源，也不单独支撑用户可见正文。

## 两类报告的证据边界

- 个股简评：允许使用当前行情、最新已披露财务/经营数据和与关注方向直接相关的公开信息，形成当前公司快照。
- 盘后风险摘要：允许使用当日行情判断市场异动、使用上次检查后的证据判断新增事件，并使用精确向前 168 小时内的公司或行业材料解释近期背景；三者必须标记不同 `monitor_role`，不得把背景写成新增事件。
- 同一官方原文确实同时支持当前快照和新增事件时可以保留；非官方媒体来源应做跨类型排重，不能为了制造差异舍弃权威事实。

## 强制校验

- 摘要、变化说明、每条 claim 和结论分别绑定 evidence ID。
- 所有引用 ID 必须存在于当前报告的证据快照。
- DataPro 证券代码会从顶层、元数据、表格列和记录行中统一提取；缺少代码或代码与目标证券不一致时不得使用。
- 事实文本中的阿拉伯数字、百分比和日期必须逐字出现在绑定证据中。
- 公司经营财务数字只能绑定 DataPro 或 `source_tier=official` 证据；媒体数字不能单独成为公司结论。
- 证据不足时返回不足状态，不用模型记忆补齐。
- 模型生成稿与确定性回退稿都必须经过独立语义审校；未完全通过时保存为 `review_required`，并在页面明确提示人工复核。
- 盘后只有行情而没有公司事件、行业或政策上下文时，只保存有具体行情证据的市场观察，风险等级保持 `unknown`；不能用检查范围或“未发现”模板凑成文章。
- “未检索到足够证据”不等于“没有风险”。后者只有在覆盖范围充分时才可表达。
- 中港股联网来源标题必须含中文；UGC、明显过期转载和 `open_web` 来源不进入报告证据。
- 文娱活动、员工运动、旅游游记、品牌盛典等非投资内容即使提到公司名称也不得进入正文。车型售价、尺寸、轴距、电机、功率、续航、配置和上市参数只允许官方来源，或至少两个独立媒体发布方交叉支持；单一媒体参数直接省略。
- 每个关注偏好单独匹配证据。由连接词组合的独立关注项拆成子主题逐项覆盖，全部覆盖为 `covered`，部分覆盖为 `partial`，只有已覆盖子主题能进入正文；`partial` 的父级 evidence ID 必须与已覆盖子主题的来源集合一致。不可拆分的单一概念要求所有语义要素在同一标题或同一句来源正文中同时出现，禁止跨句拼接。来源只命中宽泛行业词时不能标记为已覆盖；未覆盖项继续按公司、代码和用户原词精确检索。进入正文的主题必须位于约定栏目、明确回答该主题并引用自己的 evidence ID；最终仍无证据的 `watch` 偏好只进入 `preference_coverage` 审计元数据，不得借用其他证据生成正文或“待核对”占位句。
- 媒体评论、券商判断、估值逻辑、推荐逻辑和“产业优势”等定性措辞不得进入事实段落；过滤后没有实质事件内容时省略整个栏目，不生成占位句。
- 单一媒体中的政策实施、税率调整等权威性硬事实不进入确定性回退正文；普通合作、订单和项目进展可以在忠实保留发布方归因时摘要，不得改写成公司正式公告。
- 确定性回退的摘要必须由已经标准化的行情、财务或事件段落提取，不得重新使用“主要基础”“出现新进展”等无事实模板。语义审校拒绝原因写入本地用量日志，便于定位任意公司或偏好的失败，不包含密钥与完整 Provider 原始响应。

## 新旧报告

- `initial`：首次生成，没有历史比较对象。
- `new_evidence`：标准化证据指纹发生变化，变化说明必须绑定新快照中的证据。
- `no_material_change`：证据指纹未变化，系统明确显示无实质变化。

盘后检查的证据指纹不包含 `C1` 检查范围。只有 `new_event` 计入事件数；只有行情达到阈值时使用 `monitor_outcome=market_review`，不得显示成新增公司线索。`monitor_outcome=no_new_signal` 时，当前状态和历史标签显示“无新增事件”。

刷新动作保证重新检索，不保证现实世界一定出现新信息。禁止为了界面差异而替换来源、改写数字或制造事件。

## 展示规则

- 正文旁显示对应 evidence ID。
- 联网来源必须可点击并跳转到接口返回 URL。
- 联网来源标题和 URL 不自行命名；发布方优先采用正文明确署名，转载托管站点单独展示。聚合页只能支持其返回摘要中实际出现的内容。
- 联网来源进入正文后必须提炼其内容中的具体事实，不能只复述标题并追加通用观察话术；自定义偏好保留用户原词，允许通用主题词帮助检索，但证据覆盖必须通过完整语义匹配。
- DataPro 来源展示具体返回内容，不展示内部 trace、认证头或调用链信息。
- 页面显示报告生成时间与数据截至时间，不能把生成日期冒充数据日期。
- 盘后报告的 `data_as_of` 只由真实 DataPro 或联网证据决定，内部检查范围记录不得把它抬高到检查日。
- 最近交易日早于盘后检查日时，行情只能作为带实际交易日期的背景，不得计入检查日市场异动或触发风险等级。
- 历史报告保留当时的最小化来源记录，不用新来源覆盖旧报告。最小化记录包含引用所需元数据和正文派生摘要，不包含豆包搜索原始正文。
- 被筛除的无关搜索结果不得展示。`C1` 只参与内部审计；页面不得用 Provider 状态、检查计数或空栏目覆盖已经生成的真实正文。
