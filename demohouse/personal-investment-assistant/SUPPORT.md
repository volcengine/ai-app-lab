# 支持政策

## 使用问题与缺陷

- 一般使用问题请在仓库启用后使用 Discussions；可复现的软件缺陷请提交 Issue。
- 报告缺陷时请提供项目版本、操作系统、Node.js 版本、复现步骤和已脱敏日志。
- 安全问题不要提交公开 Issue，请按 [SECURITY.md](SECURITY.md) 使用私密安全报告渠道。
- Agent Plan、DataPro、豆包搜索的账号、套餐、计费或服务端故障应通过对应的火山引擎官方支持渠道处理。

## 支持范围

维护者只对最新发布的小版本提供尽力而为的社区支持，不提供响应时限或可用性承诺。当前支持范围是 README 中描述的本地单用户模式；公网、多租户和受监管生产环境需要使用者自行完成安全与合规建设。

## 不要公开提交

不要在 Issue、Discussion、日志或截图中提交 API Key、Cookie、Authorization、持仓、客户信息、未公开信息、完整 Provider 返回或受许可限制的数据内容。
